# SportEvent

Простой учебный веб-сайт для курсовой на тему **«Организация спортивных мероприятий»**.

## Стек
- PHP 8+
- MySQL 8+
- Bootstrap 5 (через CDN)

## Возможности
- Регистрация и авторизация обычного пользователя.
- Личный кабинет пользователя (просмотр мероприятий и запись на них).
- Авторизация администратора.
- Админ-панель: создание/редактирование/удаление мероприятий.
- Админ-панель: просмотр зарегистрированных пользователей и управление блокировкой (бан/разбан).
- Отдельные страницы «О нас» и «Отзывы».
- Пользователь может оставить отзыв с оценкой (1–5), администратор может удалить отзыв.
- На странице «О нас» есть форма обратной связи для клиентов.

## Установка
1. Скопируйте проект в папку веб-сервера.
2. Создайте базу и таблицы:
   ```bash
   mysql -u root -p < database.sql
   ```
3. Проверьте `config.php` и укажите свои параметры MySQL.
4. Если сайт открыт в подпапке (например `http://localhost/SportEvent`), ссылки подхватывают путь автоматически даже при переходе в админ-раздел. При необходимости можно явно указать `base_path` в `config.php` (например `'/SportEvent'`).
5. Откройте сайт в браузере.

## Если появляется ошибка "Unknown column user_id"
Это значит, что у вас старая версия таблицы `reviews`.
Сейчас проект пытается обновить структуру автоматически при открытии любой страницы.
Если нужно вручную, выполните:
```sql
ALTER TABLE reviews ADD COLUMN user_id INT UNSIGNED NULL;
ALTER TABLE reviews ADD COLUMN rating TINYINT UNSIGNED NOT NULL DEFAULT 5;
```

## Структура
- `index.php` — главная страница.
- `about.php` — страница «О нас» + форма обратной связи.
- `reviews.php` — страница отзывов (просмотр и добавление с оценкой для обычного пользователя).
- `register.php`, `login.php`, `logout.php` — регистрация/авторизация.
- `dashboard.php` — кабинет пользователя.
- `admin/dashboard.php` — админ-панель (редактирование мероприятий, бан/разбан пользователей, удаление отзывов).
- `includes/` — подключение БД, авторизация и общие шаблоны.
