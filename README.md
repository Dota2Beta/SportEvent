# SportEvent

Простой учебный веб-сайт для курсовой на тему **«Организация спортивных мероприятий»**.

## Стек
- PHP 8+
- MySQL 8+
- Bootstrap 5 (через CDN)

## Возможности
- Регистрация и авторизация обычного пользователя.
- Личный кабинет пользователя (просмотр мероприятий и запись на них).
- Авторизация администратора.
- Админ-панель: создание и удаление мероприятий, базовая статистика.

## Установка
1. Скопируйте проект в папку веб-сервера.
2. Создайте базу и таблицы:
   ```bash
   mysql -u root -p < database.sql
   ```
3. Проверьте `config.php` и укажите свои параметры MySQL.
4. Откройте сайт в браузере.

## Структура
- `index.php` — главная страница.
- `register.php`, `login.php`, `logout.php` — регистрация/авторизация.
- `dashboard.php` — кабинет пользователя.
- `admin/dashboard.php` — админ-панель.
- `includes/` — подключение БД, авторизация и общие шаблоны.
